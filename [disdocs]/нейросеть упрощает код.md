## em.hex.in_dec

**Как работало раньше:**

Брал цифры **справа налево** (от младшего разряда к старшему). Для каждой цифры запускал внутренний цикл, который умножал её на 16 ровно столько раз, каков номер её разряда:

- `"1A3"`: цифра `3` × 16⁰, цифра `A` (10) × 16¹, цифра `1` × 16².

Это медленно: для строки длиной N делалось N² операций умножения.

**Как работает теперь:**

Идёт **слева направо**, накапливая результат по формуле `result = result * 16 + цифра`:

- `"1A3"`: `0*16+1=1`, `1*16+10=26`, `26*16+3=419`.

Внутренний цикл убран — всего N проходов, один `*` и одно `+` на каждую цифру. Результат тот же, код короче и быстрее.
